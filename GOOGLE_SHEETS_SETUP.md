# Подключение Google-таблицы для приёма ответов

Ответы гостей (кто придёт, какие напитки предпочитает) будут попадать
новой строкой в вашу Google-таблицу. Настройка занимает 5 минут, один раз.

## Шаг 1. Создайте таблицу

1. Откройте [sheets.google.com](https://sheets.google.com) → «Пустой файл».
2. Назовите её, например, «Ответы гостей на свадьбу».
3. В первой строке (шапка) впишите заголовки — по одному в ячейку A1:E1:

   ```
   Время | Фамилия | Имя(на) | Присутствие | Напитки
   ```

## Шаг 2. Откройте редактор скриптов

В меню таблицы: **Расширения → Apps Script**. Откроется отдельная вкладка
с редактором кода.

## Шаг 3. Вставьте код

Удалите всё, что там есть по умолчанию (`function myFunction() {...}`),
и вставьте вместо этого:

```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = JSON.parse(e.postData.contents);

  sheet.appendRow([
    data.timestamp || new Date().toLocaleString('ru-RU'),
    data.surname || '',
    data.firstname || '',
    data.presence || '',
    data.drinks || ''
  ]);

  return ContentService
    .createTextOutput(JSON.stringify({ status: 'ok' }))
    .setMimeType(ContentService.MimeType.JSON);
}
```

Сохраните проект (значок дискеты, название можно оставить любое).

## Шаг 4. Опубликуйте как веб-приложение

1. Нажмите синюю кнопку **«Развернуть» → «Новое развертывание»**
   (Deploy → New deployment).
2. Рядом с «Тип» нажмите на шестерёнку → выберите **«Веб-приложение»**
   (Web app).
3. Заполните:
   - **Выполнять от имени:** «Я» (ваш аккаунт)
   - **У кого есть доступ:** «Все» (Anyone) — это обязательно, иначе
     форма с сайта не сможет отправить данные.
4. Нажмите **«Развернуть»**. Google спросит разрешения — разрешите
   доступ к вашей же таблице (это стандартный шаг, скрипт работает
   только с этой таблицей).
5. Скопируйте появившийся **URL веб-приложения** — он выглядит так:

   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```

## Шаг 5. Вставьте ссылку в сайт

Откройте [js/config.js](js/config.js), найдите строку:

```javascript
scriptUrl: "",
```

и вставьте туда скопированный URL:

```javascript
scriptUrl: "https://script.google.com/macros/s/AKfycb.../exec",
```

Сохраните файл — готово. Теперь каждое подтверждение анкеты на сайте
будет добавлять новую строку в вашу таблицу.

## Если в будущем меняете код скрипта

После любого изменения кода в Apps Script нужно заново
**«Развернуть» → «Управление развертываниями» → карандаш (редактировать)
→ «Новая версия» → «Развернуть»** — иначе изменения не применятся,
хотя ссылка останется той же.

## Проверка

Заполните анкету на сайте тестовыми данными и нажмите «Подтвердить» —
через пару секунд в таблице должна появиться новая строка.
