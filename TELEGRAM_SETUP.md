# Подключение уведомлений в Telegram

Ответы гостей (кто придёт, какие напитки предпочитает) будут приходить
сообщением в Telegram. Токен бота при этом нигде не будет виден в коде
сайта — он хранится в Google Apps Script, а не в браузере гостя.
Настройка занимает 10 минут, один раз.

## Шаг 1. Создайте бота

1. Откройте Telegram, найдите **@BotFather** (это официальный бот Telegram
   для создания других ботов).
2. Отправьте ему команду `/newbot`.
3. Придумайте имя бота (любое, например «Свадьба Сулеймана и Элеоноры»).
4. Придумайте username бота — должен заканчиваться на `bot`, например
   `suleiman_wedding_bot`.
5. BotFather пришлёт **токен** — строку вида
   `123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`. Скопируйте и сохраните
   её — она понадобится в шаге 4. Никому её не показывайте.

## Шаг 2. Узнайте chat_id — куда отправлять сообщения

Проще всего так:

1. Найдите в Telegram своего нового бота по username и нажмите **Start**
   (или напишите ему любое сообщение, например «привет»).
2. Откройте в браузере ссылку (вместо `<ТОКЕН>` вставьте свой токен):

   ```
   https://api.telegram.org/bot<ТОКЕН>/getUpdates
   ```

3. В открывшемся тексте найдите `"chat":{"id":` — число после этого
   и есть ваш **chat_id** (может быть отрицательным, если это группа —
   это нормально, просто скопируйте вместе с минусом).

   Если хотите получать уведомления в группе, а не в личке с ботом —
   создайте группу, добавьте туда бота, напишите в группе любое
   сообщение и повторите шаг с `getUpdates`.

## Шаг 3. Откройте редактор скриптов

Создайте новую пустую Google-таблицу на [sheets.google.com](https://sheets.google.com)
(она нужна только как «место», где будет жить скрипт — сами данные
в неё писаться не будут). В меню: **Расширения → Apps Script**.

## Шаг 4. Вставьте код

Удалите всё, что там есть по умолчанию, и вставьте вместо этого —
подставив свои значения в первые две строки:

```javascript
const BOT_TOKEN = "ВАШ_ТОКЕН_СЮДА";
const CHAT_ID = "ВАШ_CHAT_ID_СЮДА";

function doPost(e) {
  const data = JSON.parse(e.postData.contents);

  const text =
    "🎉 Новый ответ на приглашение\n\n" +
    "Фамилия: " + (data.surname || "—") + "\n" +
    "Имя(на): " + (data.firstname || "—") + "\n" +
    "Присутствие: " + (data.presence || "—") + "\n" +
    "Напитки: " + (data.drinks || "—") + "\n" +
    "Время ответа: " + (data.timestamp || new Date().toLocaleString("ru-RU"));

  UrlFetchApp.fetch("https://api.telegram.org/bot" + BOT_TOKEN + "/sendMessage", {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify({ chat_id: CHAT_ID, text: text })
  });

  return ContentService
    .createTextOutput(JSON.stringify({ status: "ok" }))
    .setMimeType(ContentService.MimeType.JSON);
}
```

Сохраните проект (значок дискеты, название можно оставить любое).

## Шаг 5. Опубликуйте как веб-приложение

1. Нажмите синюю кнопку **«Развернуть» → «Новое развертывание»**
   (Deploy → New deployment).
2. Рядом с «Тип» нажмите на шестерёнку → выберите **«Веб-приложение»**
   (Web app).
3. Заполните:
   - **Выполнять от имени:** «Я» (ваш аккаунт)
   - **У кого есть доступ:** «Все» (Anyone) — это обязательно, иначе
     форма с сайта не сможет отправить данные.
4. Нажмите **«Развернуть»**. Google спросит разрешения — разрешите
   (скрипт будет обращаться в интернет к Telegram, поэтому попросит
   подтверждение).
5. Скопируйте появившийся **URL веб-приложения** — он выглядит так:

   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```

## Шаг 6. Вставьте ссылку в сайт

Откройте [js/config.js](js/config.js), найдите строку:

```javascript
scriptUrl: "",
```

и вставьте туда скопированный URL:

```javascript
scriptUrl: "https://script.google.com/macros/s/AKfycb.../exec",
```

Сохраните файл — готово. Теперь каждое подтверждение анкеты на сайте
будет присылать сообщение в ваш Telegram.

## Если в будущем меняете код скрипта

После любого изменения кода в Apps Script нужно заново
**«Развернуть» → «Управление развертываниями» → карандаш (редактировать)
→ «Новая версия» → «Развернуть»** — иначе изменения не применятся,
хотя ссылка останется той же.

## Проверка

Заполните анкету на сайте тестовыми данными и нажмите «Подтвердить» —
через пару секунд в Telegram должно прийти сообщение.
